The map is demo/prostate-map.svg (24 zones: glands 1–4, sectors A–C, depths v and d). Click or tab to a zone. The full demo adds dataset and map selectors. A static file host is enough: the page fetches the bundle, the SVG, and the JSON. There is no application server.
